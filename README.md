# Полезные завтраки — мобильный лендинг

Одностраничник под переход из Instagram: человек жмёт ссылку в профиле и попадает
на вертикальную страницу с фото, пользой и рецептами. Свёрстан только под мобильные:
на десктопе показывается «телефон» по центру экрана.

## Файлы

```
index.html   разметка и весь текст
styles.css   стили (палитра — в :root)
script.js    появление блоков, счётчики, раскрытие рецептов, липкая кнопка
img/         фотографии
```

## Что поменять под себя

**Ссылка на кнопке.** В `index.html` найди `data-cta` и подставь свой URL:

```html
<a class="btn" href="https://t.me/твой_канал">Получить меню бесплатно</a>
```

Пока `href="#"`, кнопка просто показывает подсказку. Липкая кнопка внизу
(`class="sticky"`) ведёт на этот же блок — её менять не нужно.

**Фотографии.** Замени файлы в `img/`, сохранив имена:

| Файл | Где используется | Пропорции |
|---|---|---|
| `hero.jpg` | первый экран | вертикальная, ~9:16, лицо справа |
| `r1-oats.jpg` … `r4-smoothie.jpg` | карточки рецептов | 4:3 |
| `mood.jpg` | тёмный блок «Через неделю» | вертикальная |
| `berries.jpg` | фон финального блока | горизонтальная |

Для героя важно: слева должно быть свободное светлое место — туда ложится заголовок.

**Цвета.** Всё в начале `styles.css`:

```css
--cream:#F7F3EC;  --ink:#2C2A25;  --green:#486B3E;
```

**Тексты.** Правятся прямо в `index.html`, разметка подписана комментариями
(`ГЕРОЙ`, `ПОЛЬЗА`, `ФОРМУЛА`, `РЕЦЕПТЫ`, `CTA`).

## Локальный просмотр

```bash
python3 -m http.server 6200 -d /Users/Alex/morning-breakfast
```

Открыть `http://localhost:6200` и включить в браузере мобильный режим (⌘⌥M в Chrome).

## Публикация

Страница статическая — подойдёт любой хостинг: GitHub Pages, Netlify (перетащить папку),
Vercel, Cloudflare Pages. Достаточно залить содержимое папки целиком.

## Фотографии

Снимки из Unsplash (свободная лицензия). Для коммерческого проекта лучше заменить
на свои — так лендинг будет отличаться от сотни похожих.
